# Luka Sandvoss

**UX/UI Designer & Full-Stack Developer** — based near Bremen, Germany

I work at the point where research, interface, and code meet — usually as the one person
carrying a project from first sketch through to a shipped, working product. Currently a UX
Designer at SVB alongside freelance work, and open to the right next opportunity.

Selected independent builds: a full social platform for pixel artists, a cross-platform
AI writing companion, a media-literacy platform built for my Bachelor's thesis, and a
cozy-dark island game with its own authoring tools.
