## About

I work where research, interface, and code meet—often carrying a project from its first sketch through to a working, shipped product. I’m a UX Designer at SVB, work independently, and am open to the right next opportunity near Bremen, Germany.

My independent work spans a social platform for pixel artists, an AI writing companion, a media-literacy platform developed for my Bachelor's thesis, and a cozy-dark island game with its own authoring tools.
